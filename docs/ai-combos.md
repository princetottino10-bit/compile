# AI に覚えさせたい手筋

対戦者から挙がった手筋の一覧。カード名は書かれている値で呼ぶ (Fire0 = FIRE_1、Plague④ = PLAGUE_5)。
値と内部 ID の対応はプロトコルごとに違う (GRAVITY は値3が無く値6がある) ので、必ず data/cards.json で引く。

状態: ✅対応済み / 🔶一部 / ⬜未対応

## 進め方
1. 1つずつ、まず再現テストを書いて、AI が今その手を選べないことを確かめる
2. 評価か選択の直し方を決めて実装する (できるだけ個別カード名ではなく仕組みで書く)
3. `node scripts/ai_arena.js` で 480 戦 × 2 シードを測り、勝率が落ちていないことを確認する
4. 手筋そのものが出るようになったかは、対局中の出現回数を数えて確かめる
