# コンボのデータベース

生成物 (`node scripts/combo_db.js`)。手で書き換えない。データは data/combos.json。

**測り方**: コンボのプロトコルを含むデッキで ORACLE 同士の対戦を進め、途中の自分の手番で止めて札を植える。同じ盤面から「その手を打つ」「相方を効果なしの同じ値の札にして同じ手を打つ」「ORACLE が自分で選ぶ」を打ち、相手の手番を挟んで自分の手番を数回進めたあとの勝つ見込み (学習モデル) を比べる。

- **噛み合い**: 相方があることで、その手が他の手よりどれだけ余分に良くなったか (pt)。(その手: 相方あり−相方白紙) − (ORACLE の手: 相方あり−相方白紙)
- **相方の値**: ORACLE が自由に打つとき、相方の札があることでどれだけ良くなったか (相方そのものの強さ)
- **逃している得**: その手を打つのと ORACLE が自分で選ぶ手の差。正なら AI が打つべき手を打っていない
- **自分で選ぶ**: ORACLE がその手を自分で選んだ割合

呼び名は値 (WAR 0 = WAR_1)。± は標準誤差。

## 噛み合うコンボ
相方があると、その手が他の手より余分に良くなる (平均 2pt 以上で、0 から 2SE 以上離れている)。

### A126 WAR 0 + FEAR 1
WAR 0 を一番上に置いたまま FEAR 1 を出す。FEAR 1 で相手は手札を全部捨てて (枚数−1) 枚引き直す。その引き直しで WAR 0 の削除が起きる。

- 種類: その手番で得 / プロトコル: WAR・FEAR
- 噛み合い +2.6 ±1.0pt / 相方の値 +12.1 ±1.1pt / 逃している得 +0.4 ±0.7pt / 自分で選ぶ 75% (153盤面、自分の手番 3 回先)
