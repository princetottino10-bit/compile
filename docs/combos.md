# コンボのデータベース

生成物 (`node scripts/combo_db.js`)。手で書き換えない。データは data/combos.json。

**測り方**: コンボのプロトコルを含むデッキで ORACLE 同士の対戦を進め、途中の自分の手番で止めて札を植える。同じ盤面から「その手を打つ」「相方を効果なしの同じ値の札にして同じ手を打つ」「ORACLE が自分で選ぶ」を打ち、相手の手番を挟んで自分の手番を数回進めたあとの勝つ見込み (学習モデル) を比べる。

- **噛み合い**: 相方があることで、その手が他の手よりどれだけ余分に良くなったか (pt)。(その手: 相方あり−相方白紙) − (ORACLE の手: 相方あり−相方白紙)
- **相方の値**: ORACLE が自由に打つとき、相方の札があることでどれだけ良くなったか (相方そのものの強さ)
- **逃している得**: その手を打つのと ORACLE が自分で選ぶ手の差。正なら AI が打つべき手を打っていない
- **自分で選ぶ**: ORACLE がその手を自分で選んだ割合

呼び名は値 (WAR 0 = WAR_1)。± は標準誤差。

## 揃えに行く手筋
見つけたコンボのうち、AI が揃えに行くように評価へ入れたもの (engine.js の AI_AIM_COMBOS・aiSpeed2Score)。数字は ORACLE 同士で決着まで打った実戦 (scripts/combo_aim.js)。基準 = 入れる前、いま = 入れたあと。

### M01 WAR 0 + CHAOS 0
WAR 0 を一番上で表のまま、CHAOS 0 も一番上で表に揃える。CHAOS 0 の開始で相手が引くたびに WAR 0 で1枚削除できる。HATE 3 (削除で1枚引く) と MIRROR 4 が乗る。WAR 0・CHAOS 0 を自分の札で覆わない。

- 60局: 揃った局 0 → 7 / 勝ち 25 → 24 (盤面の検証は C001)

### M02 WAR 0 + LOVE 6 / LOVE 2
WAR 0 を一番上で表に置いてから LOVE 6 (相手は2枚引く) / LOVE 2 (相手は1枚引く) を表で出し、引かせた分を削除で取り返す。LOVE は WAR 0 が場で効くまで手札に残す。
