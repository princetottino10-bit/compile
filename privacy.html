プライバシーポリシー

COMPILE 3D ARENA (以下「本サービス」) は、ブラウザで遊べるカードゲームです。このページでは、本サービスが扱う情報について説明します。

受け取る情報

  • ゲスト対戦: 一時的な接続情報と、入力した表示名を使います。
  • ログインしたとき (Google・メール・GitHub): 認証の提供元から受け取るアカウントの識別子、メールアドレス、表示名・プロフィール情報を使います。
  • レート戦: 対戦結果、レート、対戦日時、対戦相手、選んだプロトコルを記録します。
  • ログインして遊んだ記録: CPU 戦の戦績、経験値、実績、見た目の設定、お気に入りのカード、RUN・WEEKLY・デイリーミッションの進み具合、保存したリプレイを保存します。

ログインしなくても遊べます。ログインしていないときの CPU 戦の記録などは、お使いのブラウザの中にだけ保存され、こちらには送られません。

使い道

ログイン状態の維持、オンライン対戦の成立と同期、不正利用の抑止、レートと戦績の計算、CSV での戦績出力、記録を別の端末でも使えるようにするためにだけ使います。

オンライン対戦では、対戦相手に表示名が見えます。WEEKLY のクリア者一覧に名前を載せたときは、そのとき入力した名前がほかのプレイヤーにも表示されます。メールアドレスは表示しません。

保存と共有

認証情報と記録は Supabase (データベースのサービス) に保存します。ゲーム画面の配信には GitHub Pages を使います。広告のために売ったり、第三者に渡したりはしません (法令で必要な場合を除きます)。

保持期間と削除

アカウントと記録は、本サービスを運用している間保持します。消したいときは次の方法があります。

  • ゲーム内のメニュー右上のアカウント (ACCOUNT) から「アカウントを削除」を選ぶと、アカウントと、アカウントに保存した記録がすべて消えます。
  • CPU 戦の戦績だけを消したいときは、RECORD の「記録を消す」でアカウントからも消えます。
  • うまく消せないときは、下の連絡先にアカウントのメールアドレスを添えて依頼してください。

アカウントを消すと、そのアカウントが関わったレート戦の記録も消えます。
